# ADR-0005：DeepSeek 测试策略

- 状态：接受
- 日期：2026-08-05

默认自动化测试使用 Fake Provider；人工与里程碑真实测试使用 `deepseek-v4-flash`，必须显式启用并限制请求数与并发。密钥不进入仓库、镜像、沙箱或持久日志。

DeepSeek V4 默认开启思考模式。结构化 Agent 请求显式发送 `thinking.type=disabled`，把输出预算用于最终 JSON，并降低延迟和费用。空 `content` 最多追加一次明确 JSON 指令后重试；Schema 失败最多执行一次修复请求，之后进入可观察的失败状态。

任何曾经出现在聊天、工单或终端共享记录中的测试密钥都视为已暴露，里程碑验证后必须轮换；画板只负责避免把密钥进一步写入仓库、镜像、子进程与产物。
